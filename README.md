## 🛠 Prerequisites

Your computer needs specific components to run this software. Please ensure your Windows system meets these standards:

- Operating System: Windows 10 or 11 (64-bit).
- Processor: A modern multi-core CPU, such as an Intel Core i7 or AMD Ryzen 7.
- Memory: At least 16 gigabytes of RAM.
- Graphics: A dedicated graphics card with at least 8 gigabytes of video memory. NVIDIA cards work best for diffusion tasks.
- Storage: 10 gigabytes of available space on a solid-state drive.

If you lack a strong graphics card, the software will run slower. Check your system settings to confirm your hardware meets these needs.

## 🚀 Running Your First Design

Open the program using the shortcut on your desktop. The main window provides several options for your work.

1. **Project Selection:** Choose an empty project to start a new design. Name your project so you can find it later.
2. **Input Parameters:** The software asks for specific chemical properties. Type the desired enzyme characteristics into the provided text boxes. You might describe the target molecular shape or chemical function.
3. **Model Selection:** The tool allows you to specify which diffusion engine you want to use. You may choose between different presets provided by the development team. 
4. **Execution:** Click the Start button. The computer begins the generation process. This phase takes time depending on your hardware speed. A progress bar shows the current status of your protein design.
5. **Results:** After the process finishes, the software saves the protein structure files to your project folder. You can view these files or export them for further analysis.

## 📋 Understanding The Output

DISCO generates two types of files:

- **Structure Files:** These files contain the coordinates of your new protein. You can open these in common viewers to see the three-dimensional shape.
- **Log Files:** These text files tell you about the design process. They contain data on how the model reached the result. If a calculation error happens, the log file provides details about the event.

Save copies of these files in a secure location. You can move these files to another computer or upload them to a shared database.

## 🔧 Troubleshooting Common Errors

Computers sometimes face issues during complex tasks. Use these tips to fix common problems:

- **Software Fails to Open:** Check that your graphics drivers are current. Outdated drivers often cause problems for diffusion models. Visit the website for your graphics card manufacturer to find the latest drivers.
- **Slow Performance:** Limit the number of other programs running while you use DISCO. Your computer needs all available memory to calculate protein structures.
- **Missing Files:** If the program does not save files at the end, verify you have enough disk space. You need at least 10 gigabytes to ensure the software keeps the design data.
- **Frozen Screen:** If the program stops responding, wait for five minutes. Intensive calculations take longer than expected on slower hardware.
